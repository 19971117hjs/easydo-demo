# Folge Visual Notes

Observed from the local Folge build on 2026-04-30 while reviewing the library and editor shells.

## What stands out

- The product is much flatter than the current easyDo rebuild.
- Most surfaces are plain white with thin gray borders and very light shadow, if any.
- Accent usage is sparse and functional:
  - green for primary actions
  - warm yellow in the title bar and avatar
  - blue only for specific editing affordances
- Corners are modest, closer to `8px-12px` than large rounded cards.
- Typography is practical and compact, not hero-heavy.
- Layouts feel like desktop tools, not landing pages:
  - dense controls
  - restrained spacing
  - visible borders and separators
  - little decorative gradient use

## Implication for Recorder

- Prefer compact headers over oversized hero sections.
- Prefer white cards with clear borders over glassmorphism.
- Keep the navigation chrome quiet so the recording controls carry the emphasis.
- Use green only for the primary next action.
- If a section does not need visual drama, remove it.
